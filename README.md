# CI/CD Web Application

A beginner-friendly web application for practicing a GitHub + Jenkins CI/CD pipeline.

## Technologies

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Jenkins

## Project Flow

Developer → GitHub → Jenkins → Build → Test → Deploy

## Files

- `index.html` - Web page
- `style.css` - Styling
- `script.js` - JavaScript
- `Jenkinsfile` - Jenkins CI/CD pipeline
- `README.md` - Project documentation

## How to use

1. Create a GitHub repository.
2. Upload all project files.
3. Create a Jenkins Pipeline job.
4. Connect the GitHub repository.
5. Configure Jenkins to use the `Jenkinsfile`.
6. Run the pipeline.
